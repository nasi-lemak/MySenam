# Roadmap

Ideas not yet built, and a record of what has been delivered from them.
**Nothing in the ideas table is operational.** What works is in
[feature status](../product/feature-status.md); what is broken or unverified
is in [known limitations](known-limitations.md), and fixing those comes before
anything here.

| Status | Meaning |
| ------ | ------- |
| PLANNED | Intended: what it needs is known, but it is not scheduled |
| PROPOSED | Raised by research, an audit or a conversation; no decision to build it |
| BLOCKED | Cannot start without a partner, credential, approval or decision |
| DEFERRED | Postponed on purpose, with the reason given |

A row moves to [delivered](#delivered) when its acceptance criterion is
checked, not when code exists. Research recommendations and audit findings
are added here as PROPOSED until the owner decides.

| Apple sign-in | PROPOSED | From the launch audit: the identity table already allows `apple`; needs an Apple developer account ([authentication](../architecture/authentication.md)) |
| A native app, offline mode | PROPOSED | From the launch audit: the site is responsive with a manifest and no service worker. Web push (above) comes first; a native app is a separate product |
| QuickBooks (and SQL Account, AutoCount) live accounting | PROPOSED | Xero is built behind a provider interface and unverified against Xero itself ([ADR 0041](../architecture/decisions/0041-live-accounting-push-to-xero.md)); the export for SQL Account, AutoCount and QuickBooks to import is by hand ([reporting](../features/reporting.md)). A QuickBooks adapter is not built; SQL Account and AutoCount have no common API. |
